# Engineering Risk Register — AI Office Suite

**Phase:** D0/D1 Baseline

| ID | Risk | Severity | Likelihood | Mitigation / Status |
| :--- | :--- | :--- | :--- | :--- |
| **R-01** | **ONLYOFFICE Community Edition AGPL v3 copyleft** forces open-sourcing commercial SaaS | Critical | High if adopted | Excluded Community Edition via `check-licenses.mjs`; ONLYOFFICE evaluated only under commercial Developer Edition terms. |
| **R-02** | **HyperFormula `GPL-3.0-only` copyleft** conflicts with proprietary commercial distribution | Critical | High if adopted | Excluded HyperFormula from D1 runtime; flagged for commercial license review if Handsontable+HyperFormula is chosen in SS-01. |
| **R-03** | **Tiptap Pro commercial dependency** (`@tiptap-pro/extension-pages`, export-docx/pdf) adds recurring vendor cost & redistribution constraints | High | Medium | Proved in D1 that Tiptap **MIT core** + CSS `@page` + `docx` (MIT) + headless Chromium HarfBuzz PDF works without Tiptap Pro; interactive multi-page visual page-breaking in-editor remains a D3 trade-off. |
| **R-04** | **Univer mixed open/commercial boundary** (Core Apache-2.0 vs commercial Pro XLSX exchange, charts, pivots) | High | Medium | Documented in `SPREADSHEET_FEASIBILITY_REPORT.md`; requires vendor quote before SS-01 commitment. |
| **R-05** | **Khmer Unicode cluster splitting & line breaking** corrupts `U+17D2` coeng subscripts during programmatic AI edits | High | High without guard | Mitigated in `engines/document/src/khmer.ts` via `Intl.Segmenter('km', { granularity: 'grapheme' })` range snapping and HarfBuzz PDF rendering. |
| **R-06** | **Khmer ASR Word Error Rate & EN/KM code-switching** degrades voice command reliability below 95% target | High | High | Mitigated by push-to-talk editable transcript review (`VOC-01`), deterministic planner validation, and gating live STT behind D1.02/D5 benchmark. |
| **R-07** | **Git CLI absent on development workstation** (`git` not installed, no `.git` repo initialized) | Low | Mitigated | **Mitigated:** Installed portable official `Git.MinGit v2.56.1` and initialized local repo inside `ai-office-suite/` (`v0.2.0-g1-baseline`). |
| **R-08** | **OneDrive workspace synchronization** can cause SQLite/file handle contention under heavy concurrent writes | Medium | Medium | Mitigated in dev/test via in-memory PGlite (`@electric-sql/pglite`); production PostgreSQL volumes must sit outside OneDrive-synced directories. |
| **R-09** | **Prompt injection inside imported DOCX, XLSX, or analytical prompts** attempts unauthorized AI actions or SQL execution | High | Medium | Mitigated via `scanForPromptInjection()` + `scanForUnsafeAnalyticalInput()`, allowlisted dimensions, `enable_external_access = false`, RBAC, and approval gates. |
| **R-10** | **CSV formula injection, encrypted/traversal OOXML & external rels** | High | Medium | Mitigated via ZIP traversal/OLE2/macro checks, `TargetMode="External"` warnings, and whitespace-aware OWASP CSV escaping. |
| **R-11** | **`exceljs@4.4.0` moderate `uuid <11.1.1` (`GHSA-w5hq-g745-h8pq`) & dev-only `vitest`/`tinypool` advisories; `pptxgenjs` transitive `image-size@1.2.1`** | Medium | Mitigated / Observed | Mitigated `image-size` (`GHSA-5p2g-fcmc-qvqq`, `GHSA-w3rx-r6r6-pgpr`) via root `"overrides": { "image-size": "^2.1.0" }` (`npm audit --omit=dev --audit-level=high` exits `0`). Remaining `exceljs` moderate `uuid` and dev `vitest/tinypool` tracked. |
| **R-12** | **DuckDB fixed-decimal division (`DECIMAL/DECIMAL -> floating approx`)** | Low | Mitigated in AN-00 | Mitigated in `engines/analytics/src/precision.ts` (`FIN-POL-V1`) by computing all monetary arithmetic, 10-decimal FX conversion, and division in exact `BigInt` minor units. |
| **R-13** | **Dataset granularity mismatch multiplying budgets (`invoice_line` vs `department_month_budget`)** | High | Mitigated in AN-00 | Mitigated in `BusinessAnalysisEngine` (`ANA-T05`) by rejecting mismatched granularities unless pre-aggregated to `(reportingMonth, department)` 1:1. |
| **R-14** | **LLM/AI agent multi-step financial reasoning inaccuracy (DABstep evidence ~14.55% on hardest unconstrained tasks)** | High | Mitigated in AN-00 | Enforced via deterministic `BusinessMetricRegistry` + `BusinessAnalysisEngine` as sole numerical authority and explicit `aiInterpretation.isObservedFact = false`. |
| **R-15** | **Desktop PowerPoint / LibreOffice Impress absent on dev host (`PPT-T06` reference fidelity)** | Medium | Observed | Unpacked OOXML parts & Edge HarfBuzz PDF/PNGs verified; schedule desktop PowerPoint manual test on Windows/Mac reference machine before `PS-01`. |
| **R-16** | **PptxGenJS default `notesSlide*.xml` & BI cache/policy role leakage** | High | Mitigated in PS-00/BI-00 | Verified speaker notes text is omitted when `includeSpeakerNotes: false` (`PPT-T19`), and BI caches key on `policyId:policyVersion` + dept scope (`BI-T18`) + `revokePrincipalAccess` (`BI-T19`). |
| **R-17** | **Unsafe SVG/HTML injection or callback expressions inside ChartSpec** | High | Mitigated in BI-00 | Blocked fail-closed in `validateChartSpecSafety()` (`packages/validation`) prior to ECharts/Vega-Lite compilation. |
| **R-18** | **Uncontrolled bidirectional cross-module sync corrupting certified figures** | High | Mitigated in XI-00 | Restricted default synchronization strictly `source -> target` (`ONE_WAY_SYNC_DETACH_REQUIRED` `409` unless explicitly detached). |
| **R-19** | **BOLA / hidden metadata leakage via shared dependency graphs & caches** | High | Mitigated in XI-00 | Enforced dual source-read + destination-write auth, dependency classification/column redaction (`INT-T20`), and policy-keyed cache invalidation (`INT-T24`). |
| **R-20** | **Post-approval manifest tampering or partial publication visibility** | High | Mitigated in XI-00 | Bound `PublicationApproval` to SHA-256 manifest digest (`INT-T17`) and executed atomic PostgreSQL publication + `xi_outbox_events` commit with rollback proof (`INT-T22`). |
| **R-21** | **Orphaned staged files when short commit transaction rolls back** | Medium | Mitigated in PA-00 | `LocalPrivateObjectStore.sweepOrphanedBlobs()` removes unreferenced staging blobs safely (`PLT-T20`); production S3/GCS scheduled lifecycle worker still required before `XI-06`/`PA-03`. |
| **R-22** | **Admin/billing role over-privilege leaking confidential finance or restricted Payroll data** | Critical | Mitigated in PA-00 | Mitigated via `PolicyDecisionEngine` separating `billing_admin`/`auditor` from content access and enforcing explicit `workspaceContentGrant` on `restricted` workspaces (`PLT-T09`, `PLT-T12`, `GOV-T03`). |
| **R-23** | **Privacy-unsafe LLM failover sending confidential/restricted data to non-ZDR or unapproved external provider** | Critical | Mitigated in AIC-00 | Mitigated in `ModelRoutingPolicyEngine` — missing policy fails closed (`MISSING_MODEL_ROUTING_POLICY`), external providers stay locked (`423`), and unapproved fallbacks abort with `PRIVACY_UNSAFE_FAILOVER_BLOCKED` (`AI-T02..T06`, `GOV-T05`). |
| **R-24** | **Indirect prompt injection & mid-flight ACL revocation inside corporate knowledge retrieval** | High | Mitigated in AIC-00 | Mitigated in `CorporateKnowledgeIndex` via stage-1 ACL pre-filter, untrusted instruction sanitization (`AI-T14`), and response-time `recheckCitations()` against live revocation tombstones (`AI-T17`, `GOV-T06`). |
| **R-25** | **Khmer (`km-KH`) live acoustic WER/CER and voice currency/FX ambiguity** | High | Open (Corpus Pending) | Critical-field disambiguation (`AMBIGUOUS_CURRENCY`, `FX_RATE_REQUIRED`), dictation-vs-command isolation, and org terminology registry verified locally (`VOC-T08..T23`); live consented native Khmer speaker benchmark remains **PENDING** before `VI-01`. |
| **R-26** | **Split-brain background worker commits & concurrent quota/seat oversubscription** | High | Mitigated in PA-00 | Mitigated via `SELECT ... FOR UPDATE` serialization on `pa_tenant_subscriptions` (`PLT-T05`, `PLT-T24`) and monotonic `fencing_generation` + `lease_token` checks on `pa_jobs` (`PLT-T30`, `GOV-T08`). |
| **R-27** | **Billing/quota lockout blocking SME customers from retrieving their own existing authorized work** | High | Mitigated in PA-00 | Mitigated via `isReadExistingAuthorizedWork` invariant in `PolicyDecisionEngine` — `past_due`/quota limits pause new metered AI/voice runs while preserving read/export access to existing authorized artifacts (`PLT-T27`, `GOV-T07`). |
